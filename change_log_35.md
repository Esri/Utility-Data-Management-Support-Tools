# Utility Data Management Support (UDMS) toolbox for ArcGIS Pro Change Log

## 3.5.1

* New Common Ancestor Trace tool to find the common feature/features from 2 or more starting points
* New Add Lifecycle to Asset State Attribute Rule tool to add an attribute rule to manage the AssetState network attribute from the AssetLifecycleStatus attribute
* Bug fixes for Transfer Utility Network tool to better support attachments and associations
* Configure UN Layers

  * New option - Category Definition Expression - Adds definition expressions to show/hide features with the assigned network categories.
  * New option - Terminal Use - Adds a popup to devices which displays the items connected via each terminal.
